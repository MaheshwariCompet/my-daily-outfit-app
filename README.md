# MyDailyFit 👗✨

> An anti-stress, Scandinavian-inspired wardrobe planner and daily styling companion built with **React**, **TypeScript**, **Tailwind CSS**, and **React Router**.

---

## 🌟 Brand Identity
- **App Name**: `MyDailyFit`
- **Logo**: The Hanger + Green Checkmark vector geometry.
- **Design Core**: Eliminates daily decision fatigue via a 10-second morning outfit matcher, interactive mix & match tree canvas, weekly planner, and dynamic wardrobe health audits.

---

## 🚀 Key Features

1. **Persistent Real Data**:
   - Wardrobe images, custom uploads, and scheduled outfits automatically persist in browser `localStorage`.
   - Real-time recalculation of all metrics: Active rotation %, Washed vs. In Laundry count, and Unworn pieces.

2. **Interactive Location & Weather Modal**:
   - Change city and climate (Sunny, Rainy, Cold, Windy) to immediately update styling recommendations and layer advice.

3. **User Profile & Auth Toggle**:
   - Switch between signed-in profile and guest mode with instant visual indicators.

4. **Smooth Photo Upload & Auto-Naming**:
   - Upload personal camera pictures with drag & drop and instant client-side preview.
   - Intelligent auto-naming extracts clean titles and assigns categories based on image file names.
   - Smooth vertical scrolling on all display resolutions.

5. **Independent Mix & Match Canvas**:
   - Shuffling bottom trousers in the visual branching tree only affects the canvas without altering Today's Matched Pair.

6. **Interactive Weekly Horizon & Fast Favorites**:
   - Click any day of the week to inspect and confirm scheduled outfits.
   - 1-click "Wear This Look" preset loading.

7. **Reactivating Unworn Clothes**:
   - 1-click "Wear Tomorrow" in Insights schedules forgotten garments onto the next day's hanger.
